# Communal Tech

Сайт мастерской в Уфе: гравировка, компьютеры под заказ, видеомонтаж и помощь с учебными проектами.

## Запуск

Откройте `index.html` в браузере. Это статическая страница со встроенными стилями и изображениями; сборка не требуется. Шрифт Manrope загружается из Google Fonts, а при недоступности используется системный шрифт.

Контактные кнопки ведут в Telegram, VK и на телефон. Сайт не хранит заявки и не подключён к внутренним таблицам.
